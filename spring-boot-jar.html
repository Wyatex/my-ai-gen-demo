Maven 依赖排除片段

在左侧树图或排行榜中点击任意 .jar 依赖旁的「排除」按钮，即可生成对应的 <exclusion> 配置： 

<!-- 点击任意第三方依赖即可生成 -->
<exclusions>
    <exclusion>
        <groupId>org.bouncycastle</groupId>
        <artifactId>bcpkix-jdk18on</artifactId>
    </exclusion>
</exclusions>
Spring Boot 分层镜像优化 (Layered JAR)

当 BOOT-INF/lib 占比较高但无法继续裁剪时，推荐在 spring-boot-maven-plugin 中开启分层打包，使 Docker 每次构建仅推送几百 KB 的业务代码层： 

<plugin>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-maven-plugin</artifactId>
    <configuration>
        <layers>
            <enabled>true</enabled>
        </layers>
    </configuration>
</plugin>
